🧹 HP penuh file berantakan? Biarkan AI yang beresin — dengan keamanan data tingkat produksi.

AI File Organizer v1.2 merapikan ribuan file HP / SD Card otomatis pakai Google Gemini AI, dengan antarmuka visionOS Liquid Glass. Ini adalah update stabilitas & keamanan data dari v1.1: file asal HANYA dihapus setelah salinan diverifikasi byte-demi-byte, dan proses scan/eksekusi bisa dibatalkan kapan saja.

✨ YANG BARU DI v1.2 — Stabil & Aman Produksi
• Data-safe FileMover: file asal dihapus HANYA SETELAH salinan diverifikasi penuh — tidak ada file hilang
• Dry-run murni: uji coba tidak membuat folder apa pun — benar-benar simulasi
• AI_Organized tidak ikut discan ulang — tidak ada duplikasi proses
• Fallback Gemini otomatis: 2.5-flash → 2.0-flash → lite — selalu dapat jawaban
• Progress real-time: tidak lagi indeterminate — tahu persis kapan selesai
• Tombol terkunci saat proses berjalan — anti double-execution
• Crash tahan: parsing respons AI yang tidak valid tidak menghancurkan app
• Folder pilihan tersimpan — tidak perlu pilih ulang tiap buka app
• Ikon adaptive visionOS + edge-to-edge penuh

🔒 PRIVACY FIRST
• Tidak ada data collection — tidak ada analytics, iklan, atau tracker
• API key Gemini Anda disimpan terenkripsi (AES-256-GCM) — tidak pernah ke server kami
• File TIDAK diupload utuh — hanya teks preview max ~600 karakter per file
• OCR 100% on-device via ML Kit — gambar tidak meninggalkan HP Anda
• Hanya izin INTERNET + VIBRATE — semua storage via folder yang Anda pilih sendiri (SAF)
• Open source MIT — audit source code kapan saja di GitHub

🚀 CARA PAKAI (3 langkah)
1. Dapatkan API key gratis di aistudio.google.com/app/apikey
2. Buka app → pilih folder Download / DCIM / Dokumen
3. Tap "Mulai Scan" → lihat preview → tap "Eksekusi" → file rapi otomatis!
