🧹 Messy phone files? Let AI fix it — with production-grade data safety & visionOS Liquid Glass UI.

AI File Organizer v1.2 auto-organizes thousands of files on your phone / SD Card using Google Gemini AI, with a visionOS Liquid Glass design. This is a stability & data-safety update from v1.1: source files are ONLY deleted after byte-verified copies succeed, and scans are now cancellable.

✨ WHAT'S NEW IN v1.2 — Stable & Safe for Production

• Pure dry-run: test mode creates ZERO folders — truly simulation only
• AI_Organized excluded from rescans — no duplicate work
• Automatic Gemini fallback: 2.5-flash → 2.0-flash → lite — always gets a response
• Real-time progress: no more indeterminate spinners — know exactly when done
• Lock button during processing — prevents accidental double-execution
• Crash-resistant: invalid AI responses no longer crash the app
• Folder selection persisted — no need to pick every time you open the app
• New adaptive visionOS icon + full edge-to-edge design

🔒 PRIVACY FIRST
• Zero data collection — no analytics, no ads, no trackers
• Your Gemini API key is stored encrypted (AES-256-GCM) — never goes to our servers
• Files are NEVER uploaded in full — only text previews up to ~600 chars per file
• OCR is 100% on-device via ML Kit — images never leave your phone
• Only INTERNET + VIBRATE permissions — storage access only via folders you pick yourself (SAF)
• Open source MIT — audit the source code anytime on GitHub

🚀 HOW TO USE (3 steps)
1. Get a free API key at aistudio.google.com/app/apikey
2. Open app → choose folder (Download / DCIM / Documents)
3. Tap "Start Scan" → preview results → tap "Execute" → files auto-organized!
